# 空气环境异常体验故事

> 状态：已确认并实现的普通异常 Demo 故事。  
> 通用机制：[体验流程与状态](../aios-exhibition-experience.md)。  
> 完整设计规范：[陈展设计系统](../../specs/aios-exhibition-design-system.md)。

## 1. 故事目标

展示 INT AIOS 如何从空气消杀机的 CO₂ 偏高读数出发，结合人在场与人体平稳证据进行分析，调度空气消杀机执行低扰动空气优化 Mock，并用设备运行回执和后续 CO₂ 读数说明处理结果。

主线：**头像浮窗触发空气异常 → 感知 CO₂ 偏高 → 结合人在场与人体平稳状态分析 → 决定低扰动空气优化 → 调度空气消杀机 → 等待设备运行回执 → 持续监测 CO₂ → 后续读数确认回落 → 空气状态反馈 → 记忆与回流。**

## 2. 触发、证据与等级

- Demo 入口为头像浮窗“空气环境异常”，从唤醒页重新进入完整流程；默认自动体验仍是正常故事。
- 异常证据来自空气消杀机 Mock：CO₂ 由初始 986 ppm 持续升至 1680 ppm。
- 温度 26.4℃、湿度 58%、PM2.5 18 μg/m³、VOC 正常、颗粒物稳定；睡眠带心率 72 次／分、呼吸 16 次／分保持平稳。
- 本故事由上游场景配置传入 `warning` 普通异常；组件不从 1680 或“偏高”字样自行判断等级。
- 异常语义从空间感知结果正式呈现时开始，不在采集完成前提前染黄。

上述数值只是连续 Mock，不是通用空气质量阈值、健康风险判定或真实设备验收。

## 3. 体验流程

| 阶段 | 页面内容 | 关键语义 | 颜色／组件 |
| --- | --- | --- | --- |
| 感知 | 先完成空间设备采集，结果中强调 CO₂ 偏高；再展示人体感知 | 设备测量与场景判断分开 | CO₂ 整行黄色；其他空气数据与人体进度保持正常语义 |
| 思考／分析 | 结合 CO₂ 趋势、客厅有人和人体状态，逐条展示异常依据和稳定排除项 | 只判断本轮需要进行低扰动空气优化，不把单次读数写成健康诊断；分析页静默，语音球使用 `thinking` | 过程卡、进度和语音球保持黄色事件语义 |
| 决策 | 决定启动空气消杀机进行低扰动空气优化，并继续观察 CO₂ 变化 | 是待执行设备动作，不提前宣称设备已运行或 CO₂ 已回落 | 黄色决策卡与口语告知 |
| 执行 | 确认空气优化目标、调度空气消杀机、等待设备运行回执、持续观察 CO₂ | 指令已发送≠设备已运行；设备回执≠CO₂ 已回落；进度 100%只表示本轮观察完成 | 运行步骤点、文字与进度使用黄色 |
| 反馈 | 设备运行回执和后续读数出现后，展示 CO₂ 1680→920 ppm、PM2.5 保持 18 μg/m³、人体持续平稳 | 当前为已确认的成功 Demo Mock；920 不是通用恢复阈值，也不构成真实设备能力验证 | 结果恢复后转回蓝色反馈 |
| 记忆／回流 | 将本轮事件和服务结果表达为短期“新发现”，结束后回到默认正常故事 | 不自动形成偏好、训练结果或真实存储 | 结束卡绿色环、语音球蓝色 |

## 5. 设备与组件映射

- 空气消杀机是 CO₂ 证据来源、低扰动空气优化 Mock 的执行设备和持续监测设备；睡眠带与摄像头只提供本轮人在场与人体稳定背景。
- 本轮不加入开窗／通风提醒，也不新增窗户、新风或空调控制能力。空气消杀机降低 CO₂ 的真实执行能力仍待核验，Demo 中的调度、回执和回落趋势不得视为设备能力验收。
- 复用正常故事全部页面、过程卡、结果卡、列表循环、扫光、进度、语音和转场；通过 `severity` 与指标 `tone` 传入黄色语义。
- 异常指标的序号、字段、状态点与数值全行黄色；正常人体指标和完成步骤保持自身语义。
- 详细尺寸、配色、状态列宽度、进度换色和语音生命周期见设计系统第 21 节。

## 6. 成功、未解决与升级

- **成功 Mock**：空气消杀机返回运行回执，且后续 CO₂ 读数确认由 1680 回落至 920 ppm，页面才可显示空气状态恢复平稳并转回蓝色。
- **未解决**：设备已返回运行回执但 CO₂ 未回落时，保持黄色并继续观察，不得显示优化完成。
- **无读数／升级**：当前没有可运行分支；监测失败、等待时限、升级条件和外部通知方式均待确认，不自动升为红色。

## 7. 节奏与验收

- 沿用正常故事的 8 秒稳定停留、采集完成后 2 秒、执行目标领先 1.6 秒和执行完成到反馈 6 秒。
- 重点验收：异常发现前不提前染黄；只有 CO₂ 异常整行黄色；其他空气数据和人体采集保持正常语义；思考静默；决策语音完整；设备指令、运行回执、持续监测和 CO₂ 后续读数含义分明；不出现开窗／通风提醒；反馈和回流不串场。
