# 正常状态体验故事

> 状态：已确认并实现的默认 Demo 主线。  
> 通用机制：[体验流程与状态](../aios-exhibition-experience.md)。  
> 完整设计规范：[陈展设计系统](../../specs/aios-exhibition-design-system.md)。

## 1. 故事目标

让游客在一条短而完整的自助流程中理解：INT AIOS 能持续感知人与空间，把多设备数据组织成有依据的理解，并在整体平稳时主动发起低扰动空气优化，最后用执行回执与后续数据解释结果。

主线：**静默待机 → 感知唤醒 → 空间／人体感知 → 思考／分析 → 决策 → 执行 → 反馈 → 成长日志／记忆 → 结束卡 → 回到唤醒页。**

## 2. 触发与证据

- 默认自动体验始终进入本故事；头像浮窗的异常按钮只用于切换查验故事。
- 待机阶段模拟射频检测到服务范围有一名体验者，唤醒页表达“客厅空间出现 01 人”。
- 体验者落座后，视频摄像头及分析模型提供位置、人数与基础外观估计；空气消杀机提供环境指标；睡眠带提供心率和呼吸。
- 空间感知与人体感知平级。当前先空间、后人体只是展示编排，不是业务依赖。

## 3. 连续 Mock 数据

| 对象 | 感知结果 | 来源性质 |
| --- | --- | --- |
| 人体 | 心率 72 次／分、呼吸 16 次／分 | 睡眠带 Mock 测量 |
| 环境 | 26.4℃、湿度 58%、CO₂ 986 ppm、PM2.5 18 μg/m³、VOC 正常 | 空气消杀机 Mock 测量 |
| 颗粒物 | 轻度波动 | 故事场景判断，不是真实阈值 |

反馈 Mock：温度 26.4→26.5℃，湿度 58%→59%，CO₂ 986→778 ppm，PM2.5 18→16 μg/m³；CO₂ 30 秒趋势为 986→918→842→778 ppm。这些只保证故事连续，不代表真实设备、环境效果或健康结论。

## 4. 体验流程

| 阶段 | 页面内容 | 证据与语义 | 后续 |
| --- | --- | --- | --- |
| 待机／唤醒 | 基础信息首页、加载康养场景包、发现 01 人 | 射频人在场 Mock | 引导落座 |
| 感知 | 分别展示空间与人体设备的采集进度、过程卡与结果卡 | 采集 100% 只表示本轮数据准备完成 | 结果稳定后进入思考 |
| 思考／分析 | 结合人在场、人体指标与环境指标，逐条呈现分析依据 | 分析页不播报，语音球使用 `thinking`；感知持续亮起 | 形成决策 |
| 决策 | “人体及空间状态平稳，适度优化空气环境可提升舒适度” | 这是待执行意图，不表示设备已启动 | 完整口语告知后进入执行 |
| 执行 | 确认低扰动优化目标，调度空气消杀机，增强送风并观察 | 指令发出、设备运行与指标改变分层表达 | 设备回执与后续读数齐备后反馈 |
| 反馈 | 执行结果卡、4 行指标与 CO₂ 趋势图 | 只用 Mock 回执与后续数据说明本轮结果 | 成长说明与记忆 |
| 结束／回流 | “暂无新的任务／INT AIOS将继续保持感知待命” | 绿色环表示 Demo 观察窗口结束，不是长期无事件结论 | 回到唤醒页开始下一轮 |

## 5. 主文案与语音

| 节点 | 已确认表达 |
| --- | --- |
| 唤醒 | 你好，很高兴为您服务～ |
| 决策卡 | 人体及空间状态平稳，适度优化空气环境可提升舒适度。 |
| 决策语音 | 您现在整体平稳，我会轻柔地优化一下空气，让您更舒适。 |
| 反馈主标题 | INT AIOS会反馈本次执行并／作为成长日志进入记忆 |
| 成长语音 | 我会收集日志，筛选数据作为成长经验。 |

“／”表示已确认的两行换行，不是页面可见字符。

## 6. 设备与组件映射

- 设备：射频设备负责人在场 Mock；视频摄像头负责基础视觉信息；空气消杀机负责环境测量与本轮执行；睡眠带负责心率、呼吸。不使用血压仪。
- 复用 `PerceptionPage`、`AnalysisPage`、`DecisionPage`、`ExecutionPage`、`FeedbackPage`、`AiosStatus`、`VoiceDock`、记忆与结束卡，不创建第二套页面。
- 通用卡片、进度、列表循环、扫光、渐隐、语音和转场详见设计系统第 10–16 节。

## 7. 节奏与验收

- 页面主要稳定停留 8 秒；采集 100% 后保留 2 秒；执行目标约领先过程卡 1.6 秒；执行完成到反馈 6 秒。
- 验收必须确认前后 Mock 连续、指令／回执／结果分层、持续感知高亮、分析静默、决策语音完整及结束回流不串场。
- 未确认真实采集时限、空气模式指令和效果阈值；不将当前 Mock 升格为产品参数。
