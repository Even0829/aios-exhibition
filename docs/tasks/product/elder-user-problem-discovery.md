# 高龄老人及其子女用户问题探索

## Goal

在具体服务场景与功能设计之前，围绕高龄、独居、患基础病或慢性病、轻微功能减退的老人及其子女，尽可能系统地挖掘用户问题、痛点、影响链与未满足需求，形成待验证的问题假设池。

## Sources

- `docs/knowledge/products/origin-home-eldercare.md`
- `docs/knowledge/sources/aios-product-design-base.md`

## Scope

In scope:

- 区分老人本人、异地或同城子女及其相互影响的问题。
- 覆盖健康、安全、生活能力、情绪社交、家庭协同、数字与服务使用等问题域。
- 分析问题出现的情境、表层表现、深层原因、后果、现有应对及应对缺口。
- 区分普遍问题、特定人群问题、低频高风险问题与高频慢性消耗问题。
- 明确哪些内容是来源支持的共性问题，哪些只是需要用户研究验证的产品假设。
- 以目标人群的真实生活为起点重新推导，不使用调整前的能力框架、服务案例及其优先级倒推用户问题。

Out of scope:

- 设计具体服务场景、功能、交互、设备组合或商业方案。
- 使用既有场景能力分类作为问题框架或设计约束。
- 修改 Durable Owner。
- 将未经访谈、观察或来源支持的判断写成项目事实。
- 医疗诊断、治疗建议或专业急救替代方案。

## Deliverables

- 老人与子女的用户问题全景图。
- 问题的影响链、关键矛盾与优先验证方向。
- 待验证假设和后续用户研究问题清单。

## Acceptance

### Hard Constraints

- 先问题、后方案，不用产品功能倒推痛点。
- 明确区分事实、推断和待验证假设。
- 同时呈现老人自主性与子女安心诉求，识别两者冲突。
- 不把正常衰老简单病理化，不把子女默认成唯一照护者。

### Soft Evaluation

- 覆盖面足够广，但能识别真正影响生活与家庭决策的关键问题。
- 问题描述具体到可被访谈、观察或行为证据验证。
- 为下一阶段选择高价值服务场景提供清晰依据。
