# 五类优先问题真实生活场景探索

## Goal

基于用户确认的五类优先问题，从老人及其子女的真实生活出发，构建并筛选可供后续产品解决方案设计使用的具体服务场景。

五类优先问题：

1. 居家异常难以及时发现、确认并有人处理。
2. 慢病、用药、测量和复诊计划难以长期正确执行。
3. 身体不适或指标异常时，家庭不知道下一步怎么办。
4. 出院、术后或疾病恢复回家后，专业计划执行中断。
5. 行动和生活能力缓慢下降，家庭发现得太晚。

## Scope

In scope:

- 描述真实人物、家庭关系、时间、空间、前因、事件、现有应对、困难与后果。
- 每类问题先形成候选场景，再选择最典型、迫切、难替代且有购买触发的主场景。
- 区分老人直接价值、子女付费价值与市场表达价值。
- 场景应能被后续访谈和产品方案验证。

Out of scope:

- 设计产品功能、交互、设备、算法、流程或解决方案。
- 使用调整前的能力框架、旧服务案例及其优先级倒推生活场景。
- 修改 Durable Owner。
- 将候选故事写成已经验证的用户事实。

## Deliverables

- 五类优先问题的候选真实生活场景。
- 每类问题的主场景与必要补充场景。
- 场景优先级、选择依据和待验证问题。

## Acceptance

### Hard Constraints

- 场景先于方案，不出现产品如何解决。
- 场景包含触发前、问题发生、现有应对、失败点和影响结果。
- 老人和子女视角同时成立，不以子女监控替代老人自主。
- 不夸大医学结果，不假设技术能够准确识别或处理。

### Soft Evaluation

- 像真实家庭生活，而不是展示功能的脚本。
- 能解释为什么现有方式成本高、困难或不可靠。
- 能为后续产品价值、解决方案和首期范围选择提供依据。
