# 家庭康养共用服务机制

## 规格地位

本文件是引元家庭康养五类优先服务场景共用运行机制的唯一 Owner，供具体场景规格和开发拆解引用。

它继承 [引元家庭康养产品](../../knowledge/products/origin-home-eldercare.md) 的系统原则与 [引元家庭康养核心场景能力](../../knowledge/products/origin-home-eldercare-scenarios.md) 的角色、能力和边界，不拥有产品定位、具体场景触发条件、设备品类或技术实现。

## 共用机制范围

所有具体服务场景共用：

1. 个体规律形成与使用。
2. 照护任务状态与持续处理。
3. 联系人配置、联系和升级。
4. 反馈、结果确认与任务关闭。
5. 设备健康、服务降级与恢复。
6. 空间感知、老人可达性与设备就近调度。
7. 健康与康复计划的来源、版本和变更。
8. 健康测量的可信度、复测和数据表达。
9. 健康风险分流、专业接手和场景交接。
10. 中低风险主动干预、舒缓和服务后复查。
11. 多周趋势的形成、确认和干预复查。

每个场景只配置风险等级、设备与事实、触发条件、联系对象、可接受的确认方式、关闭条件和后续任务。

## 1. 个体规律机制

- 前14天使用场景固定规则运行，同时记录作息时间、活动路径、持续时长、老人回应、任务结果和设备状态。
- 最近30天同类行为至少有5次有效记录，才形成个人参考规律；设备离线、家中有访客和已确认异常事件不计入。
- 个人正常时长上限取“近30天九成有效记录均未超过的时长”，每日更新一次。
- 个体规律只用于调整低风险服务时机和减少误扰，不得覆盖场景固定安全上限，也不得单独决定高风险升级。
- 老人或家属可以标记误报和特殊情况；纠正结果从后续计算中排除，但不删除原始任务记录。

## 2. 照护任务机制

每次服务从首次触发起只建立一个照护任务，后续变化更新同一任务，不重复创建通知。

| 状态 | 含义 |
| --- | --- |
| 后台观察 | 正常感知和记录，未打扰老人 |
| 待现场确认 | 已达到介入条件，正在向老人确认 |
| 服务处理中 | 设备或双 AI 角色正在执行服务 |
| 待人工接手 | 已联系家属或服务人员，尚无人确认接手 |
| 人工处理中 | 已有人确认接收并采取行动，但尚无最终结果 |
| 后续确认 | 当前风险已处理，仍需复查、随访或设备验证 |
| 已解决 | 有有效证据确认目标完成或风险解除 |
| 状态未知 | 无法确认老人或服务结果，任务继续保持并升级 |
| 服务受限 | 关键设备、网络或外部服务不可用，必须说明受限范围 |

“通知已发送”“消息已读”或“正在联系”都不等于任务完成。

## 3. 联系人与升级机制

### 联系人配置

- 必须设置第一联系人和备用联系人，建议增加一名能够到场的亲属、邻居、照护人员或签约服务人员。
- 每人记录姓名、关系、联系电话、App 账号、可联系时段、能否到场及获得的处理授权。
- 首次绑定时验证电话和 App；每90天重新确认一次，连续三次联系失败时立即要求家庭更新。
- 核心联系渠道为 App 高优先通知和自动电话呼叫，短信用于补充和留痕。

### 联系规则

| 风险等级 | 首期联系规则 |
| --- | --- |
| 一般协同 | 第一联系人同时收到 App 通知和自动电话；2分钟未确认接收，再联系备用联系人 |
| 紧急协同 | 第一联系人和备用联系人同时收到 App 持续警报和自动电话；60秒无人确认，联系预设可到场人员或签约服务中心 |

一般协同中，备用联系人发起后5分钟仍无人确认时：

- 任务保持“待人工接手”，前1小时每15分钟交替重试第一和备用联系人；不能因消息送达或重试结束而关闭。
- 场景风险在等待期间升高时，立即切换紧急协同，不继续等待一般协同计时。
- 已配置可到场人员或签约服务中心，且该场景不能延后到下一计划窗口时，按家庭授权继续联系；否则保留未解决事项并在下一次老人服务时再次确认。

紧急协同中，仍无人接手时，首期建议：

- 任务保持“状态未知、无人接手”，前10分钟每2分钟重试一次，之后每5分钟重试，直到有人接手或获得有效结果。
- 已配置社区、物业、照护机构或服务中心时，按授权顺序继续联系并记录接手状态。
- 未配置最终接手资源时，产品只能承诺发现和通知，不能表达已完成异常处置。
- 系统不默认自动联系公共急救机构；启用前必须明确授权、地址核验、服务接入和责任边界。

## 4. 反馈、确认与关闭机制

### 联系人反馈

子女 App 和服务端统一提供：

- 已收到；
- 正在联系老人；
- 正在到场；
- 已安排他人到场；
- 已确认老人安全；
- 老人仍需帮助；
- 需要继续升级。

前四项只更新处理进度，不能关闭任务。

### 有效结果确认

| 确认来源 | 生效条件 |
| --- | --- |
| 老人语音 | 系统明确听到确认结果；高风险事件还需结合恢复活动、回床或其他设备事实 |
| 老人实体操作 | SOS 取消或确认操作后，系统通过独立语音交互终端再次确认；不能仅凭按键关闭高风险任务 |
| 子女 App | 授权账号选择结构化结果并确认；必须记录处理结果和是否需要后续服务 |
| App 聊天或语音消息 | 系统提取结果后生成确认卡，子女再次确认才生效 |
| 在场家属现场语音反馈 | 独立语音交互终端接收反馈后，向其绑定手机发送确认卡；手机确认后生效 |
| 服务人员反馈 | 已验证身份的服务端或电话坐席记录到场、老人状态和处置结果 |

身份不明的现场语音、单一设备恢复信号和消息送达不能单独关闭高风险任务。

### 关闭与记录

关闭任务必须记录：触发事实、系统判断和不确定性、执行动作、联系人时间线、确认人和渠道、最终结果、未解决问题及后续任务。

## 5. 设备健康、降级与恢复机制

- 设备连续5分钟无有效状态或主动报告故障时，标记具体设备离线或故障，不得继续用该设备推断老人正常。
- 提示必须包含：哪台设备异常、失去什么判断能力、哪些状态因此未知、用户下一步应做什么。
- 仍可使用的设备继续服务；替代设备不足时提高人工确认等级。
- 外部网络中断时继续执行本地可完成的感知、语音终端播报与回应、照明和任务记录，并明确远程联系能力不可用。
- 服务恢复后先核对设备状态和未完成任务，再恢复同步，避免重复通知、重复执行或遗漏升级。

## 6. 空间感知与设备就近调度机制

### 空间状态

系统持续维护“老人—空间—设备”关系：

| 对象 | 必须记录的状态 |
| --- | --- |
| 老人空间 | 已确认、可能、未知；事实来源和最后更新时间 |
| 固定设备 | 固定房间、有效覆盖范围、在线状态和当前模式 |
| 可移动设备 | 固定收纳点或最近确认空间、是否有人可取用 |
| 可达性 | 同空间、老人可安全前往、需他人递送、不可达或未知 |

高风险、身体不适或需要移动的服务使用30秒内的空间事实；日常提醒和计划任务使用5分钟内的空间事实。超过时限、多人活动无法区分或不同传感器冲突时，空间状态降为“可能”或“未知”，先通过覆盖可能空间的语音终端询问，不直接调度物理设备。

### 调度前置判断

1. 先确认老人空间，再选择覆盖该空间的语音终端、电视、照明、空气净化器或传感器。
2. 血压计、体温计或药盒不在同一空间时，先判断老人是否清醒稳定、行动能力是否与平时一致、路径是否安全，并询问是否愿意前往或取用。
3. 老人清醒稳定且能够安全前往时，才可引导移动；系统同时开启路径照明，用毫米波连续确认移动，并由目标空间语音终端接续服务。60秒未到达、途中停滞或老人表示不适，立即停止引导并重新分流。
4. 家属或照护者在场时，优先请其把可移动设备送到老人所在空间，不让不适老人自行移动。

### 无法前往时的降级与升级

| 情况 | 处理 |
| --- | --- |
| 已知长期行动不便、当前状态与平时一致且无急症信号 | 取消本次跨空间移动；保留语音服务，标记测量或设备服务受限，请在场人员递送设备，或形成一般家属协同 |
| 老人拒绝前往，但可清楚回应且无异常 | 尊重拒绝，改用不依赖设备的服务或改期；需要测量结果才能继续的任务保持未完成 |
| 新出现无法起身、明显无力、步态不稳、跌倒或移动中突然不适 | 不再要求移动，立即提升风险并进入健康或安全分流 |
| 老人能力、位置或原因无法确认 | 状态记为未知；停止非必要物理设备调度，提高人工确认或协同等级 |
| 高风险已成立 | 不等待血压计、体温计或其他设备到位，直接紧急协同；设备数据只能补充，不能延误处置 |

空气净化器只对登记的当前空间执行。普通净化可在设备能力和授权范围内低打扰运行；杀菌净化或负氧离子功能须单独登记工作原理、“老人可在场使用”和有害副产物验证结果。化学因子或臭氧类模式只允许在无人空间按安全流程运行，完成后确认残留满足要求再允许老人进入；资料不完整时默认关闭。设备启动后必须复核空气读数和运行状态，不能仅凭启动成功判定环境已改善，更不能据此判定头晕、胸闷或呼吸不适已经缓解。

空气净化和杀菌边界参考[国家卫生健康委《空气消毒机通用卫生要求（WS/T 648—2019）》](https://www.nhc.gov.cn/wjw/s9488/201902/4d3708259cac429a9e94c62dbad9e6fe/files/1739781256093_68805.pdf)：物理因子空气消毒设备可按要求用于有人环境，化学因子空气消毒设备仅用于无人环境；国家卫生健康委也说明[普通空气净化器标准不直接包含病毒等病原微生物杀灭率要求](https://www.nhc.gov.cn/xcs/nwwd/202002/caf058465df54156ac3d32d063fc0041.shtml)，因此杀菌效果必须单独验证。

## 7. 健康与康复计划机制

### 计划字段与状态

每项用药、测量、训练、观察或复诊任务至少记录：内容、时间或时段、先后关系、执行条件、遗漏后的处理、风险提示、来源、确认人、生效日和失效日。

计划状态统一为“待核实、当前有效、暂停执行、已被替代、已结束”。同一事项只能有一个当前有效版本，历史版本不可覆盖删除。

### 来源与变更

- 医嘱、处方、出院记录或专业人员确认内容，须由家属或服务人员上传并核对后才成为当前有效计划；老人或家属口述先进入待核实。
- 老人说“换药、停药、改量、医生让我改训练”等内容时，创建计划冲突，不自动覆盖当前版本，也不提供自行加减、停用或补服建议。
- 冲突只限制相关计划项；系统继续执行不受影响的服务，并把当前版本、老人新陈述和待核实材料同时展示给授权家属或专业人员。
- 只有授权家属或专业人员完成结构化确认，填写新内容、来源和生效时间后，旧版本才转为“已被替代”。
- 计划变更、撤回和恢复均记录操作者、时间、依据及受影响任务。

## 8. 健康测量可信度与复测机制

每次测量记录设备、测量人、时间、测量前条件、原始读数、设备错误、复测读数和最终采用值。设备上传数值不自动等于可信结果。

首期上臂血压采集模板：

1. 使用已绑定且通过准确性验证的上臂式电子血压计；早晨按有效计划在起床排尿后、服药和早餐前进行。
2. 测量前30分钟避免吸烟、饮茶或咖啡等影响因素，排空膀胱，坐位安静至少5分钟；测量时不说话，上臂与心脏同高。
3. 连续测量2次，间隔约1分钟；两次收缩压或舒张压差值大于10 mmHg 时测第3次，记录后2次平均值，否则记录前2次平均值。
4. 条件未满足、设备报错或无法完成复测时，标记“本次测量可信度不足”，保留原始读数但不据此形成趋势或调整计划。

其他指标必须有经专业审核的独立采集模板后才能用于健康分流。家庭测量结果用于辅助判断和就医沟通，不用于系统自行诊断或改药。

上臂血压模板依据[国家卫生健康委《基层医疗卫生机构高血压防治管理标准（WS/T 872—2025）》](https://www.nhc.gov.cn/fzs/c100048/202509/2f3f7cce449145f8b361e70b3ed4ae9a/files/WS%20T%20872%E2%80%942025-20250930105429913.pdf)；产品实现不得删减其影响可信度的关键步骤。

## 9. 健康风险分流与场景交接机制

- 健康分流只读取已审核的确定性规则包；规则包必须包含适用人群、症状或指标条件、行动等级、等待时间、复查条件、禁忌、版本和审核责任人。
- 系统输出“已知事实、不确定内容、风险提示、建议下一步”，不输出疾病诊断或处方变化。
- 分流结果统一为：紧急协同、尽快专业咨询、定时复查观察。每个结果必须带明确动作和下一次检查时间，不能只说“继续观察”。
- 无法回应、出现规则包内急危重症信号或状态快速恶化时，不等待生成式模型推理，直接按紧急协同处理。
- 家属、服务人员或医疗人员确认接手后，任务保持“人工处理中”；只有获得现场结果、专业处置结果或有效复查结果才可关闭。
- 一个场景切换到另一场景时复用同一老人、事件、设备读数和对话上下文，建立关联任务，不要求老人重复描述，也不丢失原场景的关闭责任。

首期不承诺自动拨打120；紧急协同必须明确提示联系人根据现场情况尽快拨打120。未来接入公共急救前，仍须满足联系人机制中的授权、地址和责任条件。

## 10. 中低风险主动干预与舒缓机制

“没有达到高风险”不等于服务完成。系统在排除急症信号后，仍须按状态提供可执行服务并复查结果。

| 状态 | 成立条件 | 首期服务方式 | 结果要求 |
| --- | --- | --- | --- |
| 正常 | 没有不适，且有效测量和行为事实均在当前个人计划范围内 | 低打扰记录；智能空气净化器只维持已授权日常模式 | 可直接结束本次检查 |
| 低风险不适 | 老人可清楚回应，只有久坐疲劳、轻微腰背发紧、刚回家疲惫或当前空间空气不佳，且无急症信号 | 确认空间和意愿后，提供姿势改变、短时活动、电视拉伸或智能空气净化器等可逆服务 | 服务结束后确认感受；环境服务还需复核空气读数 |
| 中等健康关注 | 有效血压超出个人目标，或有轻微头晕、心慌、发冷发热、呼吸不畅等症状，但保持清醒、稳定且未命中急症规则 | 保持安全体位；同空间或安全可达时调度血压计或体温计，空气净化器只作环境辅助；按规则定时复查 | 明确改善、未改善、加重或无法确认 |
| 高风险 | 命中已审核急症规则、突然失去移动能力或状态快速加重 | 停止移动引导和普通设备服务，不等待测量，立即紧急协同 | 获得人工或专业处置结果 |
| 状态未知 | 关键设备不可用、空间或能力未知、测量不可信、老人无法回应或结果无法确认 | 停止非必要物理调度；不按低风险处理，改用人工确认或更高等级协同 | 状态得到可靠确认 |

### 主动服务动作卡

每项中低风险服务必须预先配置：适用条件、排除条件、使用设备（如有）、老人确认方式、动作及时长、停止条件、复查时间和升级条件。生成式AI只能在已配置动作卡内选择和解释，不能临时创造治疗动作。

首期共用规则：

- 先排除急症信号，再询问老人是否愿意接受服务；拉伸、环境设备和任何身体相关动作不得无确认自动启动。
- 调度前必须执行空间与可达性判断；老人不能安全前往设备空间时，按空间机制降级或升级，不以“设备在线”代替“设备可服务”。
- 低风险舒缓单次建议不超过10分钟；启动后5分钟或设备停止时确认感受。出现疼痛加重、麻木、无力、头晕、胸闷或呼吸不适立即停止并转健康分流。
- 中等健康关注在已审核规则指定时间主动复查，首期通用候选为15分钟；指标类复查仍须满足对应测量可信度模板。
- 一次复查后仍未改善，或老人明确希望家人知晓时，转“尽快专业咨询”或一般家属协同；出现加重立即提高风险等级。
- 首次中低风险服务不默认通知家属；服务未改善、反复发生、老人要求或个人计划明确规定时再协同，避免把日常照护重新转嫁给子女。
- 不增加、减少或暂停药物，不自动启动制氧机、雾化器等治疗设备。

减少久坐、量力活动和慢病人群在专业指导下运动的边界参考[国家卫生健康委《健康中国行动（2019—2030年）》](https://www.nhc.gov.cn/guihuaxxs/c100133/201907/2a6ed52f1c264203b5351bdbbadd2da8.shtml)；具体老人仍以个人健康状态和有效计划为准。

### 结果与关闭

结果统一为“已缓解、未改善、已加重、老人拒绝、无法确认”。

- “已缓解”须有老人明确反馈；涉及指标时还须有有效复测，涉及设备服务时还须有设备完成事实。
- “未改善”必须创建定时复查、专业咨询或家属协同中的至少一项，不能直接关闭。
- 老人拒绝低风险服务时，记录意愿并约定下一次观察；拒绝中等健康关注且症状仍在时，进入一般家属或专业协同。
- “已加重”和“无法确认”不能关闭，按健康分流或联系人机制继续。

## 11. 多周趋势确认机制

- 前14天只积累观察数据；形成趋势基线至少需要最近28天数据，且每周关键设备有效覆盖不少于5天。
- 趋势按7天窗口计算，与此前28天个人基线比较；设备离线、外出旅行、家中访客、已知急性不适或家属标记的特殊日不纳入。
- 首期候选触发：至少2个有效维度下降30%以上并连续2个7天窗口出现，或1个关键维度下降50%以上并连续2个窗口出现。该阈值只用于发起确认，不等同功能减退诊断，上线前需家庭试点校准。
- 触发后先向老人询问是否为主动选择、临时事件、身体不适或实际困难；不能可靠感知的做饭、洗澡和社交状态必须通过老人或家属确认，不能由活动传感器直接推断。
- 老人确认无异常时继续观察7天；趋势恢复则记录为暂时变化，仍持续则发起一般家属协同。老人确认疼痛、不适或完成日常活动困难时，转入健康或康复场景。
- 建立干预计划后14天复查同一组指标和老人主观反馈；没有复查结果不得表达干预有效。

## 12. 具体场景必须补充的内容

每份场景规格必须明确：

- 场景目标、主导角色和协同能力；
- 最低设备、增强设备及各自提供的事实；
- 固定触发条件、个体规律如何参与和固定安全上限；
- 老人侧、设备侧、子女侧和服务侧动作；
- 老人空间、设备空间、可达性和跨空间失败后的降级或升级；
- 中低风险时的动作卡、具体设备、服务时长、复查节点和升级条件；
- 风险等级、联系人顺序、反馈入口和等待时间；
- 有效确认来源、关闭条件和后续任务；
- 设备离线、网络异常、无人回应和无人接手时的降级；
- 首期验收、待验证参数和升级建议。
