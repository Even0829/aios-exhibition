# eldercare/

本目录拥有引元家庭康养具体服务机制和场景落地规格。

## Owners

- `shared-service-mechanisms.md`：五类优先服务场景共用的规律、任务、联系人、确认、设备、空间感知与就近调度、计划、测量、健康分流、中低风险主动服务和趋势机制。
- `nighttime-bathroom-no-response.md`：老人夜间起身后长时间未回床、卫生间无回应场景的首期落地规格。
- `morning-blood-pressure-medication.md`：晨间血压、服药执行与换药冲突场景的首期落地规格。
- `sudden-dizziness-chest-distress.md`：老人独自在家突发头晕或胸闷场景的首期落地规格。
- `post-discharge-30-day-recovery.md`：出院后30天用药、训练、观察与复诊持续推动的首期落地规格。
- `multiweek-functional-decline.md`：连续数周生活能力变化发现、确认和干预复查的首期落地规格。

## Reading Order

1. 读取产品与核心场景能力 Owner。
2. 读取 `../../knowledge/products/origin-home-eldercare-devices.md` 核对当前设备与逐场景组合。
3. 读取 `shared-service-mechanisms.md`。
4. 读取当前具体场景规格。

具体场景只配置本场景规则，不重复定义共用机制。
