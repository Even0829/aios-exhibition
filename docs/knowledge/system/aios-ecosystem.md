# AIOS 生态

## 系统定义

AIOS 是引态科技构建的智能体社会运行基础设施。它让智能体、设备、服务、空间、Runtime 与开发者能力被识别、调用、协作、调度和计量，并让价值按贡献回流。

AIOS 不是单一 AI 工具、聊天机器人、SaaS 平台、物联网平台、工作流产品或智能体市场。

## 当前阶段

AIOS 当前处于验证可信协作阶段。重点是证明能力可以被创建、在真实场景中被调用，结果与贡献可以记录，反馈能够推动能力改进并再次使用；当前不等于已经建成完整能力经济。

## 五产品分工

| 产品 | 定位 | 长期职责 |
| --- | --- | --- |
| 引核（Cortex） | AIOS 智能系统内核 | 负责推理、规划、运行时上下文和任务执行 |
| 引芯（Nexus） | AI 能力芯片 | 让设备拥有可信身份、位置与能力证明 |
| 引元（Origin） | AI 原生边缘枢纽 | 让 AIOS 进入真实空间并持续运行 |
| 元域（Realm） | 智能体能力养成平台 | 让智能体从经验中形成持续能力 |
| 织界（Orcha） | 能力经济网络 | 负责能力发现、协作、贡献计量与价值分配 |

五个产品不是五个彼此独立的应用，而是围绕能力关系图协同工作的产品体系。

## 协作关系

```text
需求与场景上下文进入
-> 引核理解并运行任务
-> 引芯证明现场设备身份、位置与能力
-> 引元组织空间、本地运行和设备执行
-> 结果、贡献与场景反馈被记录
-> 元域推动经验与能力演进
-> 织界支持能力发现、协作和价值流动
```

## 本项目依赖

引元家庭康养产品是 AIOS 进入家庭真实空间的产品实践：依赖引核的智能运行能力、引芯的设备证明能力，并通过引元完成家庭现场的本地运行、设备协调与真实反馈。

本项目不负责定义元域、织界、引核或引芯的完整产品方案，也不提前设计完整能力经济。
