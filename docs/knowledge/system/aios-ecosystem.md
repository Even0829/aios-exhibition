# AIOS 生态参考

## 适用边界

本文件保存旧来源的生态背景，仅在涉及其他产品关系时按需核对，不作为本项目的默认前置或新引元定义的上位约束。当前引元定义只由[引元 Owner](../products/origin.md)持有。下文 AIOS 指旧生态语境，不将其自动等同或重新排列为 INT AIOS 的上位系统。

其他产品分工、协作关系与阶段描述是既有来源口径；进入实际依赖设计时需重新核对更新材料，不据此确认当前接口、可用状态或交付情况。

## 系统定义

AIOS 是引态科技构建的智能体社会运行基础设施。它让智能体、设备、服务、空间、Runtime 与开发者能力被识别、调用、协作、调度和计量，并让价值按贡献回流。

AIOS 不是单一 AI 工具、聊天机器人、SaaS 平台、物联网平台、工作流产品或智能体市场。

## 既有来源的阶段描述

既有来源将 AIOS 描述为验证可信协作阶段。重点是证明能力可以被创建、在真实场景中被调用，结果与贡献可以记录，反馈能够推动能力改进并再次使用；当前不等于已经建成完整能力经济。

## 五产品分工

| 产品 | 定位 | 长期职责 |
| --- | --- | --- |
| 引核（Cortex） | AIOS 智能系统内核 | 负责推理、规划、运行时上下文和任务执行 |
| 引芯（Nexus） | AI 能力芯片 | 让设备拥有可信身份、位置与能力证明 |
| 引元 | 定位已由新来源更新，见[引元 Owner](../products/origin.md) | 与其他产品的实际协作关系按需核对 |
| 元域（Realm） | 智能体能力养成平台 | 让智能体从经验中形成持续能力 |
| 织界（Orcha） | 能力经济网络 | 负责能力发现、协作、贡献计量与价值分配 |

五个产品不是五个彼此独立的应用，而是围绕能力关系图协同工作的产品体系。

## 协作关系

```text
需求与场景上下文进入
-> 引核理解并运行任务
-> 引芯证明现场设备身份、位置与能力
-> 引元组织空间、本地运行和设备执行
-> 结果、贡献与场景反馈被记录
-> 元域推动经验与能力演进
-> 织界支持能力发现、协作和价值流动
```

## 本项目使用

康养产品以[引元](../products/origin.md)及其通用系统模型为底座。旧来源中的引核运行、引芯设备证明等协作仅供跨产品问题参考，未重新核对前不作为当前方案的必选技术依赖。

本项目不负责定义元域、织界、引核或引芯的完整产品方案，也不提前设计完整能力经济。
