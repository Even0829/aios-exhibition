# products/

本目录拥有具体产品的可持久化事实。产品定位、服务对象、形态、工作方式和边界只在对应 Owner 中定义。

## Owners

- `origin-home-eldercare.md`：本项目主体“引元家庭康养产品”的产品总 Owner，包含产品定义与首期架构设计原则。
- `origin-home-eldercare-scenarios.md`：核心场景能力 Owner，包含双 AI 服务角色、五大核心场景能力、价值定位、能力边界和能力内示例。
- `origin-home-eldercare-devices.md`：《五个优先具体服务场景设备清单》Owner，包含当前五个场景已经使用的设备、后续建议增强设备和逐场景设备组合。
- `origin.md`：引元产品定义与知识主线；通用对象和运行机制继续读 `../system/origin-system-model.md`。

## 陈展专项

- `aios-exhibition-context.md`：陈展目标、受众、设备输入、事实边界与来源；陈展专项工作的业务入口。
