# 五个优先具体服务场景设备清单

## 知识地位

本文件是当前五个优先具体服务场景跨场景设备总览、配置状态和场景设备组合的唯一 Owner。

当前设备必须已经出现在五个场景规格的“成立条件与设备”或“完整服务流程”中；设备在单个场景中的触发、调度、降级和验收仍由对应场景规格拥有。后续建议增强设备不得被当作当前场景成立条件。

本文件不按五大核心场景能力分配固定设备套餐，也不涉及品牌、型号、价格、供应商、合作或接口方案。

## 收录规则

- 当前设备：已在五个具体服务场景中承担感知、交互、执行、确认或协同作用。
- 后续建议增强：能提升当前五个场景，但尚未进入现行场景流程或成立条件。
- 同一设备可跨场景复用，不因出现在多个场景重复采购或重复定义。
- 所有物理设备调度复用[家庭康养共用服务机制](../../specs/eldercare/shared-service-mechanisms.md)的空间感知、可达性、设备健康、结果确认和风险升级规则。
- 新设备必须先进入具体场景并说明闭环价值，再进入本总览的“当前设备”。

## 一、当前五个场景已经使用的设备与服务端

| 设备或产品端 | 当前定位 | 已使用场景 | 作用与关键边界 |
| --- | --- | --- | --- |
| 引元盒子 | 五场景共同中枢 | 全部五个场景 | 汇集事实、判断风险、创建任务和调度设备；本体不拾音、不播报 |
| 独立语音交互终端 | 五场景共同交互设备 | 全部五个场景 | 当前空间主动播报、远场拾音、老人回应和双向通话；必须按空间配置和验证覆盖 |
| 家庭电视 | 视觉服务设备 | 晨间血压与服药、出院后30天恢复、多周生活能力下降 | 展示大字步骤、康复动作、读数和阶段结果；电视关闭不阻断非视觉任务 |
| 子女 App | 远程协同端 | 全部五个场景 | 接收事项、确认接手、反馈结果和管理计划；消息送达不等于问题解决 |
| 毫米波传感器 | 共同空间与活动感知设备 | 全部五个场景 | 提供在场、空间、活动、久坐、离床、持续静止和疑似跌倒线索；不能诊断疾病或单独证明安全 |
| 门磁 | 出入事实设备 | 夜间卫生间无回应、多周生活能力下降 | 提供开门和出入事实；不能单独证明老人位置 |
| 智能联动照明 | 路径与环境执行设备 | 夜间卫生间无回应、晨间血压与服药、出院后30天恢复、多周生活能力下降 | 开启夜间或跨空间路径照明；照明成功不等于老人已安全到达 |
| SOS 紧急求助设备 | 主动求助设备 | 夜间卫生间无回应、突发头晕或胸闷 | 老人主动触发求助；不能用普通语音终端替代唯一紧急入口 |
| 智能上臂式血压计 | 健康测量设备 | 夜间场景健康接手、晨间血压与服药、突发头晕或胸闷、出院后30天恢复 | 提供血压和脉搏；须按规范完成可信测量，不能自行诊断或改药 |
| 智能电子体温计 | 健康测量设备 | 夜间场景健康接手、突发头晕或胸闷、出院后30天恢复 | 提供体温事实；只按症状或有效计划使用，不要求完成无关测量 |
| 智能提醒药盒 | 用药执行与确认设备 | 晨间血压与服药、出院后30天恢复 | 提醒正确药格并记录开盒；开盒不等于已经服药 |
| 智能空气净化器 | 当前场景增强设备 | 突发头晕或胸闷、出院后30天恢复、多周生活能力下降 | 提供当前空间颗粒物、运行和滤芯状态并执行净化；杀菌净化和负氧离子须验证在场安全，不能作为治疗或症状解除依据 |

## 二、后续可建议增强的设备

以下设备尚未进入当前五个场景的核心流程或成立条件：

| 建议增强设备 | 可增强的当前场景 | 建议价值与采用边界 |
| --- | --- | --- |
| 智能门锁 | 夜间卫生间无回应 | 增加入户授权和更丰富的门锁状态；首期门磁已经满足开门、出入事实，智能门锁不作为场景成立条件 |
| 智能按摩背垫 | 出院后30天恢复、多周生活能力下降 | 增加经确认的非术区、低强度、限时舒缓；首期以休息、体位调整、短时活动和电视拉伸完成闭环 |
| 厨房家电智能插座、浴室用水传感器 | 多周生活能力下降 | 增加指定家电用电或浴室用水事件，丰富生活趋势事实；事件仍不能证明由老人完成，也不能直接判断做饭或洗澡质量 |
| 授权视频终端或摄像头 | 夜间卫生间无回应、出院后30天恢复、多周生活能力下降 | 辅助异常复核、亲情视频或专业动作观察；必须单独授权，不默认持续监控，也不能单独证明动作正确 |
| 健康穿戴设备 | 夜间卫生间无回应、突发头晕或胸闷、多周生活能力下降 | 补充外出活动、移动 SOS 和部分健康线索；受佩戴与充电影响，不替代家庭毫米波或固定 SOS |
| 备用蜂窝通信与后备供电设备 | 全部五个场景 | 增强断网、断电后的本地运行和紧急联系连续性；启用前需在场景规格中补充失效切换与恢复验收 |

未在本表出现的健康或治疗设备不自动进入建议范围；后续须由明确具体场景、用户确认和安全规则重新评估。

## 四、跨场景组合规则

- 先确认老人空间、设备空间和安全可达性，再调度语音、测量、舒缓或环境设备。
- 老人行动稳定且同意时，可由智能照明、毫米波和目标空间语音终端协同引导前往；突然无力、步态不稳或原因未知时停止移动并升级风险。
- 防潮语音对讲终端只在卫生间语音覆盖验收不通过时成为当前必配；普通语音终端不能用理论距离代替现场验证。
- 血压计和体温计只补充健康事实；高风险成立时不等待设备到位。
- 智能空气净化器是首期可逆的中低风险服务设备，须按设备能力和场景规则调度并在服务后复查。
- 智能门锁、智能按摩背垫、厨房家电智能插座和浴室用水传感器不参与首期闭环；接入后必须补充对应场景的触发、确认、异常和验收规则，才能转为当前设备。
- 当前条件设备离线时只撤销对应事实或动作，不让无关场景整体停止。

## 后续维护

- 场景新增、删除或改变设备时，先更新对应场景规格，再同步本文件的当前设备总览和场景组合。
- 仅有产品设想但尚未进入场景流程的设备放在“后续可建议增强”，不得混入当前基础组合。
- 本 Owner 不延伸到品牌、型号、价格、供应商、合作或接口判断。
